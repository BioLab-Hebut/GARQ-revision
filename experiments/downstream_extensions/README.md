# D18 downstream extensions (R13/R14)

Original source archives for adding MetaQ to the matched downstream controls,
the six-arm 25507-cell common intersection analysis, and MetaQ genome-wide
LinkPeaks. Private path prefixes are normalized; scientific code is preserved.
They use frozen native memberships, not newly fitted or size-equalized groups.

These extensions depend on the already published ../matched_association/code
workflow, the saved native assignments, matching feature lists, original
annotation/coordinate objects, and the archived input directory layout. The
common-cell script accepts explicit root paths; the MetaQ and LinkPeaks entries
use the environment variables documented below. Code dependencies resolve to the
already-public matched_association/code directory.
No cell-level memberships, matrices or R objects are bundled.

## Release entry points
From the repository root, first use `experiments/matched_association/prepare_workflow.py` with a JSON
path map to create an independent prepared code directory. Include the TF
reference-coefficient and reference-matrix paths from `code/source/compare.R`
in that mapping, as well as raw data and annotation paths. This changes paths
in a new copy without changing the public source. Set
`GARQ_ASSOCIATION_CODE=/path/to/prepared/code` so these extensions execute and
hash the same prepared dependencies. Check that no `/workspace/garq` prefixes
remain in inputs used by the chosen workflow.

```bash
python experiments/matched_association/prepare_workflow.py --path-map path-map.json --output-root /path/to/prepared
export GARQ_ASSOCIATION_CODE=/path/to/prepared/code
```

From this extension directory, configure `GARQ_ASSOCIATION_INPUT` (historical analysis root), `GARQ_METAQ_ASSIGNMENTS`,
`GARQ_D18_RAW` and `GARQ_METAQ_OUTPUT`. `metaq_matched_controls.py` imports the
already-public `../matched_association/code` modules. Preserve their original
input layout and required source/annotation files; see that workflow's README.
The historical membership identity and all three matching seeds are retained.

```bash
python metaq_matched_controls.py
python common_cell_controls.py --old-root /path/to/matched_association_inputs --raw-root /path/to/D18_raw --metaq-assignment /path/to/metaq/cell_assignments.csv --output-root /path/to/new/common_cells
GARQ_LINKPEAKS_INPUT=/path/to/linkpeaks_inputs GARQ_METAQ_ANALYSIS=/path/to/metaq_matched/analysis GARQ_LINKPEAKS_OUTPUT=/path/to/new/linkpeaks Rscript run_metaq_linkpeaks.R matched_seed1 MetaQ
```

Run the LinkPeaks command for matched_seed1, matched_seed2 and matched_seed3.
No new gene/peak annotation or biological data is generated by these path adapters.
